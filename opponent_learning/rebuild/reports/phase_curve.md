## Постаудит — что из выводов выше отозвано

После запуска `04_diagnostics.py` две части моей интерпретации оказались артефактами.

### Отозвано #1: "Стартовая позиция несёт сигнал (V_w=0.34 vs V_l=0.30)"

В таблице `mean_v_winners/mean_v_losers` для bin [0.00, 0.05) числа 0.34 / 0.30 действительно различаются. Но это **артефакт смешения 1v1 и FFA**. Когда стратифицируем по `n_players`:

```
n_players=2 (1v1):  V(winners)=0.475  V(losers)=0.476  gap=-0.001  p=0.30
n_players=4 (FFA):  V(winners)=0.269  V(losers)=0.269  gap=-0.001  p=0.61
```

Внутри страт **сигнала нет**. Симметрия стартовой позиции подтверждена также на raw features: `median diff` между игроками на step=1 во всех ratio'ах = **0.0000**. Карта генерируется идеально симметрично, модель это правильно отражает.

### Отозвано #2: "Два архетипа партий — early decisive и late decisive"

Бимодальность `argmax |dV/dt|` (25% в фазе ≈0, 25% в фазе ≈0.99) оказалась **артефактом** boundary effects свёртки `np.convolve(mode='same')`. На краях ряда kernel обрезается → ослабленное усреднение → ложно большие dV/dt на крайних точках → argmax падает в эти ложные пики.

Проверка с разными методами:

```
method            median   %<0.1   %>0.9
raw               0.375    9.1%    0.4%      ← унимодальное
smooth_k5         0.255    47.0%   32.2%     ← бимодальное (артефакт)
k5_drop10pct      0.392    0.4%    0.0%      ← унимодальное
k5_drop20pct      0.408    0.0%    0.0%      ← унимодальное
```

Бимодальность **полностью исчезает** при отбрасывании первых/последних 10% точек партии или при отказе от свёртки. Реальное распределение унимодальное с центром около **phase ≈ 0.40**, std ≈ 0.20. Никаких "архетипов" early/late decisive нет.

### Что осталось значимым

| Наблюдение | Статус |
|------------|--------|
| AUC растёт с phase как S-кривая (0.60 → 0.99) | ✅ реально |
| Игра решается во второй четверти партии (типичный argmax ≈ 0.4) | ✅ реально |
| Critical slowing down (peak of var(V)) | ❌ не обнаружено — variance монотонна |
| Резкий фазовый переход | ❌ не обнаружено — гладкая S-кривая |
| Бифуркация V(winners) vs V(losers) во времени | ✅ реально (расходится плавно) |
| Стартовая позиция несёт сигнал | ❌ артефакт смешения 1v1/FFA |
| Два архетипа партий | ❌ артефакт boundary effects |
| Bimodality V распределения растёт с фазой | ✅ реально (но это просто V → 0 или 1) |

### Что это значит для дальнейших шагов

Чистая картина после диагностики:
- Партии стартуют симметрично, V ≈ 0.5 (для 1v1) на старте
- Сигнал плавно нарастает
- Типичная фаза решения — около 0.40 ± 0.20
- После phase ≈ 0.55 — endgame шум для BC обучения

Концепт "фазового перехода в физическом смысле" не подтверждён. Это просто плавное затухание неопределённости. Идеи "найти критический момент / архетипы / специальные сигнатуры" — снимаются.

Что остаётся в плане как реальные следующие шаги:
1. **Filter BC training**: phase ≤ 0.55, и желательно AUC из value_v2 ≤ 0.85 (т.е. где модель ещё не уверена — это самые информативные примеры)
2. **Counterfactual leverage в q1-q2** (phase 0.0–0.5, где скилл реально различает игроков) через choice_sets.csv — это теперь главное направление
3. **Map-space spatial features** (поле контроля в R², топология) — единственная не пробованная категория структурных признаков. Имеет смысл попробовать **только** в зоне q1-q2, где макро ratio'ы дают AUC < 0.85 и есть пространство для улучшения
