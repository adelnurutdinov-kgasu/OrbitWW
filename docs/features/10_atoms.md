# Атомарные сущности

Базовые объекты игры. Из них собирается всё.

## Planet

`code:orbit_sim.py:Planet`

Поля (порядок в кортеже obs):
- `id` — int, уникальный
- `owner` — int: `0`=мы, `1`=враг, `-1`=нейтрал
- `x, y` — координаты центра в момент `t` (для орбитальных вращаются)
- `radius` — размер **диска** (для коллизий с флотами), `_prod_to_radius(prod)`.
  Чем больше prod — тем больше диск.
- `ships` — текущий гарнизон, всегда `≥ 0`.
- `production` — прирост ships/ход, всегда `≥ 0`. Применяется engine'ом
  **только если `owner ≥ 0`** (нейтралы не растут).

Свойства:
- Орбитальные ↔ статичные: `is_orbital(x, y, radius)` (`code:shooting.py`).
  Орбитальные — те, у которых начальная позиция вне rotation-limit zone.
- Орбитальные крутятся со скоростью `state.omega` вокруг центра поля.
- **Орбитальный радиус** (расстояние центра планеты от центра поля)
  не хранится явно — вычисляется из текущих x, y.
- Поле `size` или подобное — **нет**, только `radius`.

См. [[20_intrinsic]] для derived-фич.

## Fleet

`code:orbit_sim.py:Fleet`

Поля: `id, owner, x, y, angle, from_pid, ships`.

Движение и коллизии (`code:orbit_sim.py:simulate_step` ~340):
- Каждый ход: `(fx, fy) → (nx, ny)` со скоростью `_fleet_speed(ships)`.
  Чем больше ships в флоте — тем медленнее.
- Сравнивается **отрезок шага** `(fx,fy)—(nx,ny)` с планетами:
  `point_to_segment_dist(p.x, p.y, fx, fy, nx, ny) < p.radius` → флот пойман.
  Учитывается дискретный шаг, не точечное прохождение.
- **Sun-collision**: `point_to_segment_dist(CX, CY, fx, fy, nx, ny) < SUN_R`
  (SUN_R = 10). Флот пропадает.
- **Out-of-bounds**: `0 ≤ nx, ny ≤ 100`. Если шаг выходит — флот пропадает.

После проверок: если попал → в `combat_queue[planet_id]`. Иначе позиция обновляется.

Связь с атаками: каждый запуск порождает Fleet, который потом резолвится
в [[40_action_plans#combat-resolution]].

## Sun

Один объект в центре поля (`CX=50, CY=50, SUN_R=10`).

Влияет на:
- **Блок траектории**: `segment_hits_sun(a.x, a.y, b.x, b.y, safety=SUN_SAFETY)`
  с `SUN_SAFETY=1.5` — буфер вокруг диска для планирования.
- Не учитывается как «гравитационное» поле — только preventive geometry.
- В engine'е столкновение с солнцем — мгновенная смерть флота (см. Fleet).

См. [[30_pairs#sun-block]].

## Time

- `state.step` — текущий ход (0-индекс).
- `TOTAL_STEPS = 500` (kaggle default).
- `state.omega ∈ [0.025, 0.05]` — **равномерное распределение** (`rng.uniform`).
  Зафиксирована per-game на старте, не меняется.
- Seed используется один раз в `generate_map(seed)` для:
  - выбора `omega`,
  - расстановки планет (через `_place_group(rng)`),
  - распределения prod-тиров.
  После генерации поведение детерминировано (см. `code:local_match.py` для воспроизводимости).

См. [[50_gul_context#phase]].

## Player

- `player_id ∈ {0, 1}` — наш и противник.
- `NEUTRAL = -1` — особое значение для нейтралов.
- Engine двух-игроковый (`n_players=2` всегда у нас).
